摘  要

由于城市中汽车数量越来越多，传统的停车场管理模式存在车位占用率不高、人工收费效率低下以及信息孤岛等问题。现有的管理模式无法满足大量同时停车的需求，造成车辆进出拥堵、资源浪费的现象发生。为了缓解这些问题，建立一个良好的停车场管理系统十分有必要。这个系统的主要目的是提高停车场内资源分配的有效性，在前后端分离的基础上进行开发，利用一个网站对所有的车位、订单信息以及支付过程进行集中控制，从而避免车位分布不合理以及人工核算容易出现错误的情况。
系统以Spring Boot作为后台主要开发技术，Vue完成页面的展示以及响应式交互，数据库使用MySQL进行数据的存储。系统包含车辆管理、车位管理和收费中心等功能模块。普通用户可以进行月租车位预定、临时车位预定并绑定自己的车辆；停车场工作人员可对车位情况进行实时更新并且完成临时车位的收费后让客户离开；系统管理员可以查看整个系统的运行情况还可以给各个停车场分配相应的权限并进行财务审查。系统运行良好，功能完善，实现了停车的在线办理。此项目提高了停车的效率也为城市的停车资源优化提供了一个有效的解决方案。

关键词：停车场管理系统；Spring Boot；Vue；MySQL

Abstract

The ever-increasing number of vehicles owned by urban citizens means that conventional models of parking management are experiencing difficulties like low space utilization, the inefficiency of manual payments, and data silos. Conventional approaches are not capable of supporting high-concurrency vehicle requirements and thus cause congestion in entering and exiting and mismatch in resources. In order to reduce these pain points, building an effective and reliable parking management solution is highly practical. The main aim of this system is to improve the efficiency of resource allocation. It seeks to realize the concept of closed loop management of the car park space, order data, and payment process using a single online platform to effectively overcome the current situation of imbalance in the space and man-made errors through the adoption of a front end and backend separation paradigm.
The system is based on the Spring Boot framework to implement back-end logic, takes advantage of Vue to provide the responsive interaction of the front end and uses MySQL as the database storage. The functions modules are vehicle management, space control and a payment center. The regular users do monthly rentals, temporary parking orders, and vehicle bindings. Parking managers manage dynamic space maintenance and temporary parking check-outs. System administrators conduct general data monitoring, parking lot authorization and financial auditing. The system operates smoothly and has strict logic which allows the flow of online parking activities. Such accomplishment enhances the effectiveness of management and gives a trustworthy technical solution to the maximization of urban parking facilities.

Keywords: Parking Management System;Spring Boot;Vue;MySQL

绪  论
研究背景
停车场管理以往一般由人工完成。当车进入停车场时发给一张纸卡，然后工作人员手工记下进入时间，这种方式很容易造成入口堵塞尤其是在高峰期 REF _Ref223213114 \r \h [1]。车主寻找停车位没有方向性，在场内盲目寻找，造成资源浪费。传统的手工收费非常麻烦，车主离开时用现金进行支付需要很长时间，而且容易发生财务损失或者账目错误等问题。由于城市的汽车拥有量迅速增加，这种方式已经不能满足当今社会的需求 REF _Ref223213124 \r \h [2]。计算机技术和数据库的应用使信息处理发生改变，行业的标准化也促使管理模式发生变化。市场竞争的压力使物业公司不得不寻找更加有效的管理模式，客户的便捷停车需求也日趋多样化，在数据整合以及信息共享上传统的管理方式已不能满足需要，而研发一种可以实现自动化的停车系统的出现是大势所趋 REF _Ref223213131 \r \h [3]。
研究意义
该系统投入使用后，车位周转率大大提高，在车辆进出过程中，程序自动完成车辆识别工作，过去的人工操作导致的误操作不再发生。资源分配由计算机进行计算，工作人员可以及时了解停车场的情况，不需要再浪费时间去巡场。因为支付转到在线上进行，所以财务核算准确无误，而且流程精简节省了大量的开支。这有利于整个停车行业规范化发展，企业的竞争优势也在技术进步之中日益凸显。管理层获得的信息更准确，管理的行为由凭经验转变为依据信息做出判断，服务质量由于有统一的标准而保持一致。该类系统所建立的信用体系对社会公共资源进行分配具有一定的借鉴意义，而且能够起到良好的示范作用，推动附近的相关行业的发展。而随着这类系统的大规模推广，也将有效解决城市交通问题，在建设智慧城市中起到很好的实践经验的作用。
 论文研究主要内容
系统开发主要围绕停车场相关业务逻辑进行线上化改造，主要包括整个系统从底层数据库到前端页面全部内容。后端逻辑主要是基于Spring Boot对各项功能进行集成，当有车辆进入时所引起的变化会立即被持久层框架保存到数据库中。权限管理设计保证普通用户、停车场管理员以及系统管理员可以在自己职责范围内正常操作，不同级别的菜单访问规则都在后端代码中有明确规定。车位管理部分可以将停车位的状态变化反映到屏幕上，在线生成月卡以及临时收费并完成整个交易过程都可以做到准确无误。
前端页面基于Vue框架进行开发，采用组件化方式进行开发提高页面可复用性；用户端主要考虑移动端使用体验，车主可便捷实现车辆绑定、缴费充值、会员续费等功能，同时有页面回显让用户清楚了解整个交易流程。管理员后台具备数据分析能力，车位使用情况以及收入情况、订单分布以图形方式展现给管理者，便于其做决策。系统测试对大量车辆同时进入停车场情况做出优化，在各个接口之间调用关系上也做了很多次的压力测试，从而保证整个停车管理系统能够在真实环境中良好运行。
国内外现状
国内研究现状
国内停车管理方面的研究是从传统的手工现场管理发展到现在的全方位智能化、远程化的过程，在最初的阶段主要集中在底层硬件传感器的研究上，现在已经发展到基于云计算、大数据等技术综合平台的研究，系统的形态也从单一的进出管理发展到了包括找车位、远程看护、精准收费等功能的一体化系统。技术的发展提高了停车资源分配的效果，使管理更公开透明，也为缓解城市的停车问题奠定了坚实的基础。
杨正鑫等人在2025年对停车场电子计时收费装置量值传递准确性进行研究，从无计量标准等方面分析问题原因并给出建议，即建立公用计量标准以及促进科技发展 REF _Ref223213139 \r \h [4]，这对本文设计自动计费逻辑以及保证收费合理性有重要借鉴意义。孙芸丽等人在2025年提出一种基于车道云远程值守信息化平台解决方案，使用物联网技术来获取车位信息并对其进行分析以节省开支同时提高工作效率 REF _Ref223213144 \r \h [5]，其对于云端通信方式的设计启发了本文管理员概览部分统计数据展示方式。薛翔泽于2025年为解决大型地下停车场寻车问题设计一款支持线上线下的寻车软件，在提高用户体验基础上进行服务设计 REF _Ref223213148 \r \h [6]，而其中对于多种情况进行考虑的设计思想也被应用到本系统中的车辆管理和订单查询功能的人机交互上。
国内已有相关工作已经从底层计量精度、云端部署以及移动端导航等方面形成了一套较为成熟的技术方案。而本文的工作主要是在此基础上充分利用之前的工作对于计费准确性和远程监控的思想，在普通用户的会员中心建设、不同类型的停车订单之间的转换等方面进行更深入的研究。同时利用Spring Boot提供的可靠性和Vue提供的良好用户体验感对之前的各个模块进行整合，从而实现从车辆入场到出场结算的一站式服务。
国外研究现状
国外对于停车管理相关研究工作也表现出明显资源优化及架构标准化特征，在边缘计算方面减少系统时延的基础上还试图制定一种通用软件架构使系统具有更好的复用性，即如何用较少计算能力做到精准高效地监测是国外研究热点问题，基于数据驱动的决策支持系统是目前国外主流方向，代表较高智能化程度。

国外的研究在技术上对于资源利用效率及架构设计有较深研究特别是在边缘认证的应用上处于领先地位。而在系统功能实现的过程中，借鉴了国外文献中的双触发以及标准化的设计理念，融入到符合我国支付手段及管理方式的功能模块中，在展示车位利用率的同时也实行多层次的身份认证，使该系统不仅能够完成基本的停车工作而且更加注重管理的合理性和系统的稳定性。

关键技术介绍
Spring Boot框架
Spring Boot框架以约定优于配置的原则降低企业级应用开发复杂度，在其中内置了自动配置功能可以根据类路径下jar包加载相应组件而不需要开发者进行过多配置工作。由于停车场管理系统中业务逻辑对于稳定性的需求很高，所以此框架中的内嵌Servlet容器可以让程序单独启动而无须部署到外部应用服务器上 REF _Ref187754463 \r \h [10]。而在编写月租功能或者订单相关操作时就可以使用它所提供的依赖注入能力来提高代码复用率从而增强整个系统灵活性以及可维护性。
微服务的理念在Spring Boot中得到很好的体现，Spring Boot中的starter组件可以方便地引入常用的持久化或者安全相关的第三方库，在此基础上进行开发大大提高开发效率，在一种统一的标准下进行编码 REF _Ref187754473 \r \h [11]。停车场信息维护、订单管理等功能都是基于此框架的MVC模式实现。这种分层结构很好地分离出请求处理以及业务逻辑，利用声明式事务保证支付信息保存时的一致性，对整个停车场管理系统打下坚实的后端基础。
Vue 框架
Vue 是一种渐进式 JavaScript 构建工具，在现代前端 Web 开发中发挥重要作用。它基于 MVVM 设计理念使用双向数据绑定方式分离视图和数据之间的关系，使前端开发者可以更加关注业务代码编写工作，在实现月租服务以及临时停车页面过程中，由于是数据驱动视图从而订单状态会自动变化 REF _Ref187754480 \r \h [12]。而且分组件开发可以把车管子系统或者会员中心等都抽象成一个个可以重用的小部分。这样不仅有利于提高工作效率同时也有利于后期维护大量的页面并且给用户提供良好的使用感受。
虚拟 DOM 是 Vue 为了提高页面渲染效率所使用的技术，在内存中保存一份表示当前页面节点的数据结构，然后根据需要更新的数据比较新旧两个虚拟 DOM 之间的差异并只重新渲染发生变化的部分。这一方法对于展示管理系统中的统计数据等经常变化的信息非常有效，可以很好地应对大量数据变化而不影响页面流畅性 REF _Ref187754488 \r \h [13]。而系统管理员对停车场管理和收费管理的操作中，Vue 的路由管理帮助其便捷地从一个页面跳转到另一个页面。利用生命周期钩子函数，在前端代码中就可以对每个部分何时被加载进行严格把控，进而达到按需分配资源的目的，打造高效SPA。
MySQL 数据库
MySQL数据库以其优秀的查询速度以及很高的稳定性成为适合小型到中型的应用程序保存数据的选择。它可以支持标准的结构化查询语言并且可以很好地处理由停车场管理系统产生的大量的订单和客户信息等 REF _Ref187754503 \r \h [14]。从物理上讲，由于它是多线程运行所以可以同时服务多个不同的用户的需求。月租车订单以及临时停车流水都存储在不同的表内并通过主外键的关系保证了这两部分之间的联系。这是一种关系型数据库设计方式对于支付管理和车辆信息保存都有很好的限制作用而且即使有很多的人同时使用也是很快捷的。
索引优化以及事务处理都是 MySQL 的强项，在涉及到金钱交易的支付日志查询上也起到了至关重要的作用。合理的使用 B+树索引可以让数据库管理员从成千上万条信息中迅速找到所需的数据，减少响应时间 REF _Ref187754511 \r \h [15]。停车场管理系统中的各种增删改查等操作均由这个数据库引擎提供的行级锁来保证不会出现数据竞争的问题。视图以及存储过程的应用简化复杂的业务逻辑包装，保证底层数据的安全性的同时，也给前端提供一个良好的数据接口，支持整个系统的运行。
B/S 模式
B/S模式是浏览器和服务器模式，在把系统的大部分业务逻辑放在服务器的基础上使客户端变得简单。用户只需要用常见的浏览器就可以使用停车场管理系统，不需要下载专用桌面应用程序，大大减少系统的安装及使用的难度 REF _Ref187754518 \r \h [16]。一般用户如果是办理月租车或者查询缴费情况等所有操作都是向浏览器提交请求然后由远端服务器进行回应。这种方式的优点是可以方便地对整个系统进行管理和更新只需要改动服务器上的程序就可以让所有的客户端都用上最新的功能模块有利于实现跨平台使用。
三层架构是B/S模式的一种常见实现方式，把表现层、业务逻辑层以及数据访问层分开。系统管理员对停车场进行管理或者查看整个系统的概况时，浏览器只是用来显示数据，而繁重的计算工作是由高性能的服务器来完成。这样大大降低客户机端的要求，从而使这个系统能够在各种各样的便携式设备或者办公计算机上正常工作。据相关报道显示B/S模式在当今的信息化建设中有着良好的经济效益 REF _Ref223214940 \r \h  \* MERGEFORMAT [17]。由于网络的发展，B/S模式不但提高了信息的交互效率而且利用统一的身份验证使得多种角色的操作变得更加安全可靠。系统可扩展性也得到充分发挥，在此基础之上可以很好的满足随着停车场变大而产生的业务量增加的需求。

测试方案及测试用例 
测试方案
测试方法是保证软件或者系统质量的重要手段，根据测试的目标和需求的不同，选择不同的测试策略。常见的测试方法有黑盒测试、白盒测试、灰盒测试、回归测试、性能测试。
黑盒测试关注软件的功能表现，不关心其内部结构。测试人员输入数据，观察输出结果，验证软件是否满足需求，可用于功能验证和接口测试。白盒测试主要是对系统内部结构的检验，测试者依据对代码的了解对代码的逻辑、控制流、数据流等进行检查，保证代码的每一条路径、每一个语句都被覆盖到，找到逻辑错误或者性能瓶颈。灰盒测试综合了黑盒测试和白盒测试两者的优点，测试人员在一定程度上了解系统内部结构的同时，既关注系统的功能，又关注系统的安全性和集成性。
回归测试就是软件修改或者更新之后，重新测试已经完成的功能，新版本没有引入新的缺陷或者问题。性能测试主要是检验系统在不同的负载、压力下所表现出的性能，查看响应时间、并发处理能力等性能指标。
采用这些测试方法可以对软件的功能、性能、稳定性进行评价与改善，最终交付的系统符合用户需求，软件质量得以提升。

　结　论
本研究聚焦于现代城市停车资源分配效率低下的痛点，设计研发了基于SpringBoot后端框架与Vue前端架构的停车场管理系统。研发工作遵循科学的软件工程生命周期，通过详尽的业务需求调研，确立了以B/S模式为核心的交互蓝图。系统设计阶段对底层MySQL数据库执行了规范化建模，确保车位实时状态信息流转过程保持高度的一致性。编码实现环节完成了功能模块的逐一落地，普通用户端集成了月租申请、临时停靠预约、车辆信息维护等功能。停车场管理员侧重于现场车位的动态监控，针对场内车辆执行离场结算操作，系统管理员则负责全局范围内的停车场资源调度。后续的单元测试与集成测试验证了业务闭环的完整性，各项性能指标均达到了预定的开发标准。该系统的成功构建不仅为车主提供了便捷的线上支付途径，更为管理方提升车位周转率提供了数字化的技术支撑，有效缓解了传统停车管理过程中信息不对称带来的拥堵难题。
现阶段系统运行状态趋于稳定，但在部分细节功能的深度挖掘方面仍暴露出些许局限。支付功能目前停留在沙箱模拟阶段，未能接入真实的金融结算接口，导致线上资金流转在实际应用环境下尚需进一步调试。系统在车位推荐逻辑上欠缺复杂的路径规划算法支持，用户进入场内后搜寻具体泊位的时间成本依然存在优化空间。由于单机服务器性能限制，平台在面对极端海量并发访问时面临潜在的响应延迟风险。未来的优化路径将聚焦于引入地图API实现精准的车位导航，通过对接实时支付渠道提升交易过程的安全性。系统计划引入大数据分析手段，根据历史停车记录绘制用户消费画像，为月租服务的动态定价提供决策参考。随着智慧城市体系的不断完善，该系统的广泛应用势必推动停车产业向着更加规范的方向演进，为构建和谐的交通环境贡献实际的社会应用价值。
